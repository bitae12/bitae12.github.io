편집 철학

  1. 구조가 먼저, 이펙트는 나중

    Act 구조(도입–전개–클라이맥스–마무리)를 먼저 잡습니다. 교육 영상은 “정보의 계단”이 보여야 이탈이 줄어듭니다.

  2. 소리가 화면보다 먼저

    rough cut 단계에서 대화·음악·앰비언스를 early mix합니다. 음량 밸런스가 맞지 않으면 컷이 아무리 좋아도 아마추어처럼 느껴집니다.

  3. 숏폼은 다른 문법

    롱폼의 긴 호흡을 그대로 가져오지 않습니다. 별도 타임라인에서 훅·자막·SFX 밀도를 다시 설계합니다.

  4. 피드백은 감정이 아니라 가설

    “32초 컷이 길어서 이탈 가능”처럼 가설과 대안 컷 타임코드를 붙입니다.

  5. 출시 후가 시작

    업로드 후 리텐션·CTR을 보고, 필요하면 썸네일-safe 재편집을 제안합니다.

Process

협업 & 피드백

저와 일할 때

  1. 아침 15분 sync 선호, 오후는 편집 몰입.
  2. 소스 폴더 규칙 (`01_Footage` … `04_Export`).
  3. 급한 수정 가능, 범위 creep은 일정에 반영 요청.
  4. 구체적 피드백이 성장에 도움.

역할 경계

제가 하는 것함께 / 위임
편집, 1차 mix/color최종 마스터링
자막 타이밍·스타일번역 품질
리뷰 버전 관리법률 최종 판단

리뷰 올릴 때

  • Frame.io 또는 스프레드시트 타임코드 필수
  • 태그: delete / shorten / swap / fix audio / fix color
  • 가능하면 레퍼런스 링크

제가 드리는 리뷰 형식 예시

[00:01:12] ISSUE: 오디오 dip 너무 깊음
HYPOTHESIS: BGM이 대사를 덮음
SUGGESTION: -3dB → -1.5dB, 또는 BGM mute 0.5s

Revision 라운드: v01 rough → v02 fine + temp mix → v03 picture lock → v04+ legal/client. 보통 3라운드 안에 picture lock 목표.

납품 전 체크리스트

  • 프레임 rate / resolution spec 일치
  • Safe title margin (Shorts UI)
  • Audio peak -1dBTP 이하
  • BGM 라이선스 PDF 또는 library ID
  • Episode number / date on slate
  • Captions spelling (고유명사)
  • Export filename convention
  • Backup project + NAS archive
